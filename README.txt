SHADOW PORTFOLIO TEMPLATE
=========================

Files:
- index.html (Home)
- about.html
- projects.html
- blogs.html
- style.css
- script.js
- assets/

How to run:
1) Open the "portofolio website" folder.
2) Double-click index.html (or use Live Server in your editor).

Personalize content:
1) Open index.html
2) Replace:
   - "Your Name Here"
   - "Student Developer | AI Builder"
   - College, hobbies, interests (about.html)
   - Project titles/descriptions (projects.html)
   - Blog titles/descriptions (blogs.html)
   - Social links (# placeholders)

Replace profile image:
1) Put your photo in assets/ and name it profile.jpg
2) Keep image roughly square for best circular crop
3) If profile.jpg is missing, the site shows initials fallback automatically

Optional project images:
- The current project cards use built-in gradient placeholders.
- If you want custom images, change each .project-media block in index.html
  to an <img> element and style as needed in style.css.

Accessibility and UX included:
- Semantic HTML sections
- Sticky keyboard-friendly navigation
- Smooth scrolling
- Reduced-motion support
- Responsive mobile + desktop layout

Notes:
- No JS frameworks used.
- Lightweight CSS/JS only.
